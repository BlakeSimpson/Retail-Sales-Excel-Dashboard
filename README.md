# Retail-Sales-Excel-Dashboard

An interactive Excel dashboard for analyzing retail sales performance, featuring dynamic visualizations, KPIs, and data-driven insights.

## Data Source
Dataset sourced from [Kaggle](https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset). 

## Tools & Features
- Pivot Tables
- Slicers for interactive filtering
- Data Cleaning & Transformation
- KPI Metrics (Revenue, Units Sold)

## Key Questions Answered
- Which department generates the highest revenue?
- How do sales vary by price point?
- What are the trends over time?
- What is the demographic profile of our customers

## Purpose
This project was built to simulate a real-world retail analytics dashboard and demonstrate data visualization and analysis skills in Excel.
